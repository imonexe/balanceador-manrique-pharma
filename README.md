# Balanceador químico · Manrique Pharma

Aplicación web educativa para balancear ecuaciones químicas y comprobar la conservación de átomos y carga.

## Funciones

- Coeficientes enteros mínimos calculados con álgebra lineal exacta.
- Paréntesis, corchetes, hidratos, estados de agregación, iones y electrones.
- Resultado con subíndices, copia al portapapeles y tabla de verificación.
- Desarrollo algebraico desplegable para estudiar el procedimiento.
- Diseño Dark Science adaptable a celular, tableta y escritorio.

## Ejecutar

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

El resultado de producción se genera en `dist/`. No requiere backend ni guarda datos fuera del dispositivo.

## Recursos

- Logo y dos ilustraciones florales proporcionados por la usuaria para Manrique Pharma.
- Tipografías DM Sans e Instrument Serif, servidas por Google Fonts.
- Iconos de Lucide, incluidos como dependencia del proyecto.
